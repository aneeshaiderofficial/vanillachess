# Contributing to Vanilla Chess ♟️

Thank you for your interest in contributing to Vanilla Chess!

This project is a vanilla JavaScript chess game built with HTML, CSS, and JavaScript. Contributions that improve the game are welcome.

## How to Contribute

### 1. Fork the Repository

Create a fork of this repository to work on your own copy.

### 2. Create a Branch

Create a new branch for your changes:

```bash
git checkout -b improve-chess
```

### 3. Make Your Changes

You can contribute by:

- Fixing bugs
- Improving chess rules and gameplay
- Improving the user interface
- Optimizing performance
- Improving accessibility
- Suggesting new features

### 4. Test Your Changes

Before submitting your contribution:

- Make sure the game runs correctly.
- Test your changes in the browser.
- Ensure existing features continue to work.
- Check that your changes do not introduce bugs.

### 5. Submit a Pull Request

1. Push your branch to your fork.
2. Open a Pull Request against the main branch.
3. Clearly explain what you changed and why.
4. Wait for review.

All contributions are subject to review and approval by the project owner.

## Code Guidelines

- Keep the code clean and readable.
- Use meaningful variable and function names.
- Avoid unnecessary dependencies.
- Follow the existing project structure.
- Keep changes focused and relevant.

## Reporting Bugs

If you find a bug, open an Issue and include:

- A description of the bug.
- Steps to reproduce it.
- Expected behavior.
- Actual behavior.
- Screenshots, if helpful.

## Feature Requests

Feature suggestions are welcome! Open an Issue to describe your idea and explain how it could improve the game.
